# Glossário rápido

- `main`: branch principal e estável.
- `develop`: branch de integração para trabalho em andamento.
- `feature/...`: branch criada para desenvolver uma mudança específica.
- `merge`: operação que integra mudanças de uma branch em outra.
- `conflito`: situação em que o Git não consegue decidir sozinho como combinar alterações.
