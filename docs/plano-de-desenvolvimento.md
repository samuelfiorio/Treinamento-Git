\# Plano de Desenvolvimento



Durante este treinamento, utilizarei a branch develop como branch de integração.



Cada nova funcionalidade será desenvolvida em uma branch feature, permitindo que as alterações sejam feitas de forma isolada e organizada.



Quando uma funcionalidade estiver pronta, ela será integrada à develop por meio de um merge. Após a validação das alterações, a develop poderá ser incorporada à main.
